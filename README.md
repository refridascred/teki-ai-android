# Teki AI for Android

A Brawl Stars trophy pushing bot that runs on the phone itself. Developer: Scred. Discord: https://discord.gg/BCkPJXyCWq

## Download

Get the latest `TekiAI-x.y.z.apk` from [Releases](https://github.com/refridascred/teki-ai-android/releases/latest) (Android 8+, 64-bit phones).

## Install

1. Open the APK on the phone and allow "Install unknown apps" when asked.
2. Open Teki AI and allow the three permissions:
   - Accessibility (required). If Android says "Restricted setting", open Settings > Apps > Teki AI > the three dots (top right) > "Allow restricted settings", then turn Teki AI on under Accessibility.
   - Display over other apps (required).
   - Microphone (optional, for game sound in REC videos).
3. Open Brawl Stars once, then go back to Teki AI and tap START.
4. When Android asks what to share, choose "Share one app" and pick Brawl Stars.
5. In Brawl Stars tap UI on the right edge, add a brawler under BRAWLERS and tap START.

## Updates

Teki AI checks this repository for new versions itself: an "Update available" card appears on its start screen. Tap UPDATE and allow Teki AI to install apps when Android asks.

## Beta

This is an early version. Use it at your own risk; automating a game can break its terms of service.
